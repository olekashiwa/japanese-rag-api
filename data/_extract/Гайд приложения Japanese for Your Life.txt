Гайд-бук по функциям приложения "Japanese for Your Life"
🎯 Что есть в приложении
📖 Режим изучения — карточки с иероглифами, значениями и примерами
✍️ Режим теста — проверка знаний значений иероглифов
🔄 Режим повторения — система интервальных повторений (SRS)
✍️ Практика письма — рисование иероглифов на canvas
📤 Экспорт/Импорт — сохранение и восстановление прогресса
📊 Статистика — отслеживание прогресса и серий занятий
🔊 Аудио-произношение — озвучивание иероглифов и слов
📚 Полная база данных по уровням
N5: 158 иероглифов (все основные иероглифы начального уровня)
N4: 150 иероглифов (хорошая база для продолжающих)
N3: 370 иероглифов (полный список!)
N2: 368 иероглифов (почти полный список)
N1: 279 иероглифов (начальная база для высшего уровня)
💡 Рекомендации по использованию
Начните с N5 — изучите все 158 иероглифов
Переходите к N4 — закрепляйте знания
Используйте режим теста для самопроверки
Практикуйте написание в режиме практики
Регулярно повторяйте с помощью SRS-системы
Экспортируйте прогресс для резервного копирования
🎯 Главные режимы
Кнопка | Функция | Что делает
N5/N4/N3/N2/N1 | Выбор уровня | Переключает между уровнями сложности иероглифов. Количество иероглифов в уровне показано в скобках.
📖 К изучению | Режим изучения | Показывает карточки с иероглифами, значениями и примерами.
✍️ Тест | Режим проверки | Запускает тест на знание значений иероглифов.
🔄 Повторение (X) | Режим повторения | Показывает только иероглифы, которые нужно повторить по системе интервальных повторений. X — количество.
⏰ Только для повторения / 📚 Все иероглифы | Фильтр | Переключает между показом всех иероглифов и только тех, что требуют повторения.
✍️ Практика письма | Тренажёр | Открывает canvas для рисования иероглифа. Можно рисовать мышкой или пальцем на сенсорном экране.
📤 Экспорт | Сохранение прогресса | Скачивает файл `.json` с вашим прогрессом (изученные иероглифы, статистика).
📥 Импорт | Восстановление прогресса | Загружает ранее сохранённый файл прогресса. Как использовать: нажмите кнопку, выберите файл `.json`, подтвердите загрузку.
🔄 Сброс прогресса | Полный сброс | Удаляет всю историю изучения. Начинаете с нуля.
📖 Режим изучения (карточка иероглифа)
Элемент | Функция
Большой иероглиф | Основной иероглиф для изучения
Черты: X | Количество черт в иероглифе
Значения | Перевод иероглифа на русский
Показать чтения / Скрыть чтения | Показывает/скрывает онъёми (китайское чтение) и кунъёми (японское чтение)
Примеры слов | Слова с этим иероглифом, их чтение и перевод
◀ Предыдущий / Следующий ▶ | Навигация по списку иероглифов
✅ Знаю / ❌ Не помню | Самооценка. Влияет на систему повторений (SRS).
✍️ Режим теста
Элемент | Функция
Большой иероглиф | Иероглиф, значение которого нужно угадать
Поле ввода | Введите значение иероглифа на русском
Проверить → | Проверяет ответ и показывает правильный
Счёт: X | Количество правильных ответов
Прогресс | Какой по счёту вопрос
🔄 Режим повторения
Элемент | Функция
Большой иероглиф | Иероглиф для повторения
❌ Не помню | Помечает иероглиф как "не выучен". Показывает правильный ответ.
✅ Знаю | Помечает иероглиф как "выучен". Переходит к следующему.
Следующий иероглиф → | Появляется после нажатия "Не помню"
Индикатор прогресса | Показывает, сколько иероглифов осталось повторить.
✍️ Практика письма
Элемент | Функция
Серое поле (canvas) | Место для рисования иероглифа мышкой или пальцем
🗑️ Очистить | Стирает всё нарисованное
✅ Проверить | Анализирует рисунок и даёт оценку (0-100%)
Оценка | Показывает результат проверки (🎉 Отлично! / 📝 Попробуйте ещё раз)
📊 Статистика (вверху экрана)
Показатель | Что означает
📊 Изучено: X% | Процент изученных иероглифов в текущем уровне
🔥 Серия: X дней | Непрерывная серия дней с изучением (streak)
✅ Правильно: X/Y | Соотношение правильных ответов к общему количеству в тестах
⚠️ Важное примечание по импорту
При нажатии 📥 Импорт нужно:
1. Выбрать файл `.json`, который был ранее экспортирован
2. После загрузки страница перезагрузится
3. Весь прогресс (изученные иероглифы, статистика, серия) восстановится
Файл импорта должен иметь формат:
```json
{
"progress": { ... },
"stats": { ... },
"exportDate": "...",
"version": "1.0"
}
```
