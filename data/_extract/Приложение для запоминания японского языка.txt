После внимательного изучения статьи по ссылке. Описанное там приложение «Удобный пересказ» — это инструмент для синхронного чтения и запоминания текстов на двух языках (оригинал и перевод).
Чтобы переделать его под запоминание японского языка, нужно добавить несколько ключевых функций, которых нет в текущей версии. Вот план по его адаптации, разделенный на обязательные и дополнительные улучшения.
1. Критически важные доработки (без них не имеет смысла)
Японский язык кардинально отличается от европейских. Поэтому базовая синхронизация строк здесь не работает.
Проблема в текущей версии | Решение для японского
Разная длина строк: «長い日本語の文は…» vs «Длинное японское предложение…» — синхронизация по номеру строки ломается. | Синхронизация по абзацам или предложениям. Разбивка должна идти не по принудительным переносам, а по знакам препинания (。！？) или точкам с запятой.
Иероглифы (кандзи) без чтения: Невозможно прочитать незнакомое слово. | Автоматическая подстановка фуриганы (чтений кандзи) над иероглифами. Это можно сделать через API (например, Google Cloud Natural Language или библиотеку kuromoji.js).
Нет контекста перевода: Одно японское слово может иметь 10 значений. | Всплывающая подсказка (по клику) с вариантами перевода конкретного слова в контексте предложения.
2. Функции для активного запоминания (карточки)
Текущее приложение — это пассивное чтение. Для запоминания нужна активная проверка.
Режим «Закрой оригинал»: Вы видите только перевод на русском, а ваш текст на японском скрыт. При клике на русскую фразу открывается японский вариант для самопроверки (как «перевернуть карточку»).
Режим «Заполни пропуск»: Приложение автоматически удаляет ключевые слова (глаголы или иероглифы) из японского текста, а ученик должен вписать их с клавиатуры. Это тренирует письмо и грамматику.
Режим «Аудио»: Добавить синтез речи (TTS) для японского текста. Озвучивание строки при клике критически важно для запоминания произношения (интонации и долготы звуков).
3. Специфический словарь и структура
Поддержка частиц (は, が, を, に и т.д.): Подсвечивать их другим цветом в предложении. Для изучающих это ключевой ориентир.
Разбор по типам слов: Сделать возможность при нажатии на слово видеть его часть речи (существительное, глагол, прилагательное, наречие).
Импорт текста: В текущей версии пользователь сам делает переносы. Для японского это неудобно. Нужно, чтобы приложение автоматически разбивало вставленный текст на предложения (по 。) и абзацы (по пустой строке).
4. Итоговый алгоритм действий для переделки (пошагово)
Оставить текущий движок, но заменить механизм синхронизации с «по строкам» на «по предложениям».
Подключить библиотеку для фуриганы (например, wanakana.js для чтения хираганой и jsdom для рендеринга ruby-текста над кандзи).
Добавить базу данных (JSON) для пользовательских словарей, чтобы он мог добавлять свои переводы для нестандартных слов.
Внедрить локальный TTS (Web Speech API) — в современных браузерах это работает бесплатно и без интернета.
Создать переключатель режимов на главном экране: «Чтение», «Пересказ», «Карточки» и «Диктант».
В итоге
Суть идеи из статьи («синхронный перевод как караоке») идеально ложится на изучение японского. Главная доработка — не в интерфейсе, а в интеллектуальной обработке японского текста. Сделать акцент на работу с иероглифами и озвучивание, чтобы получилась не просто «читалка», а полноценный тренажер.
