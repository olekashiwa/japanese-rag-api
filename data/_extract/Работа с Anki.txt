Работа с Anki
TSV (Tab-Separated Values) — это текстовый формат для хранения табличных данных, где значения в строке разделены символом табуляции.
В чём суть
Каждая строка файла — это одна запись (строка таблицы).
Поля внутри строки отделяются друг от друга табуляцией (\t), а не запятой.
Расширение файла обычно .tsv.
MIME-тип: text/tab-separated-values.
Пример TSV-файла (в виде текста)
text
name	age	city
Alice	28	Moscow
Bob	34	St. Petersburg
Charlie	22	Kazan
Если открыть такой файл в текстовом редакторе, видно табуляции между полями; в Excel или Google Sheets данные автоматически распределяются по столбцам.
TSV vs CSV: главные отличия
Параметр | TSV | CSV
Разделитель | Табуляция (\t) | Запятая (или точка с запятой в некоторых локалях)
Конфликты с данными | Реже: табуляция редко встречается в тексте | Частые: запятые часто есть в текстах и числах
Экранирование | Почти не нужно | Нужно для кавычек и спецсимволов
Удобство для кода | Хорошо подходит для скриптов и импорта в БД | Требует аккуратности при парсинге
Поэтому TSV часто выбирают, когда в данных много запятых (например, адреса, описания, тексты), чтобы не усложнять парсинг экранированием.
Где применяется
Обмен данными между системами (ETL, выгрузки из БД).
Подготовка датасетов для анализа (особенно если данные содержат запятые).
Импорт/экспорт в BI-системах, базах данных, ML-пайплайнах.
Хранение простых таблиц, которые должны быть человекочитаемыми и легко парситься кодом.
Учитывая твой интерес к анализу данных и работе с CSV-файлами в pandas, TSV — это почти та же задача, только с другим разделителем.
Как читать TSV в pandas
python
import pandas as pd
df = pd.read_csv('data.tsv', sep='\t')  # sep='\t' — ключевой момент
print(df.head())
Как сохранить DataFrame как TSV
python
df.to_csv('output.tsv', sep='\t', index=False)
Как открывать и редактировать TSV
Excel / Google Sheets: при импорте указать разделитель «табуляция».
Текстовые редакторы: Notepad++, VS Code, Sublime Text — удобно для проверки структуры.
Командная строка: cat, head, awk — быстро посмотреть первые строки или отдельные колонки.
Python: pandas, csv с delimiter='\t', io.StringIO для тестов.
Нюансы и частые проблемы
Если в данных случайно есть табуляции — структура ломается.
Пробелы вместо табуляций — частая ошибка при ручном создании: тогда парсер видит не то количество колонок.
Кодировка: лучше явно использовать UTF-8, особенно если есть кириллица.
Связь с твоими задачами
Так как ты работаешь с CSV и pandas, переход на TSV — это просто смена параметра sep. Это полезно, например, если ты готовишь журнал рецептов для кофе (с описаниями, местами обжарки, вкусовыми нотами), где в текстах часто встречаются запятые: TSV избавит от проблем с экранированием и сделает выгрузку чище.
Если скажешь, для какой задачи тебе нужен TSV (например, «хочу выгрузить данные из базы», «нужно подготовить файл для Excel», «планирую использовать в пайплайне на Python»), подскажу конкретный пример под твой кейс. 😊

Как импортировать в Anki
Сохрани текст выше в файл anki_terms.tsv в кодировке UTF-8 (в VS Code, Notepad++ и т. п. это явно выбирается).
В Anki: Файл → Импорт.
Выбери файл, тип импорта укажи «TSV» (или «Текст, разделённый табуляцией»).
Настрой поля: ru → Front, en + jp → Back (или как тебе удобнее).
Тип карточки выбери простой «Basic» или свой шаблон.
Вариант с кодом/примерами (если хочешь карточки «термин + пример»)
Если хочешь сразу с коротким примером кода, можно добавить четвёртое поле example:
text
ru	en	jp	example
переменная	variable	変数	x = 5
функция	function	関数	def f(x): return x*2
цикл	loop	ループ	for i in range(3):
Тогда в Anki будет 4 поля: ru, en, jp, example.
Python-скрипт для генерации TSV
Учитывая твой интерес к анализу данных и pandas, вот простой скрипт, который генерирует такой TSV из списка словарей:
python
import csv
terms = [
{"ru": "переменная", "en": "variable", "jp": "変数"},
{"ru": "функция", "en": "function", "jp": "関数"},
{"ru": "цикл", "en": "loop", "jp": "ループ"},
{"ru": "условие", "en": "condition", "jp": "条件"},
]
with open("anki_terms.tsv", "w", encoding="utf-8", newline="") as f:
writer = csv.DictWriter(f, fieldnames=["ru", "en", "jp"], delimiter="\t")
writer.writeheader()
writer.writerows(terms)
print("TSV создан: anki_terms.tsv")
Запусти — получишь готовый файл для импорта.

Что внутри по файлам
Уровни обжарки — 浅煎り / 中煎り / 深煎り
В японских обжарочках именно эти термины на упаковках. Плюс технические термины: ハゼ入り (точка первого треска), 昇温速度 (rate of rise), 出釜温度 (drop temp) — пригодятся, если будешь разбирать японские roast-логи или общаться с обжарщиками.
Устройства
Особенно полезные для Японии: 細口ポット (gooseneck kettle — в кофейнях часто используется), 手挽きミル (ручная кофемолка — японцы любят Hario и Commandante), 屈折計 (рефрактометр — для TDS-измерений).
Оценка по SCA
Десять критериев оценки по SCA Cupping Protocol: 香り, 風味, 余韻, 酸味, ボディ, バランス, 均一性, クリーンカップ, 甘味, 総合評価. Плюс пороги: 80点以上 — спешелти, 85+ — excellence, 90+ — exceptional.
Меню кофеен
Здесь собраны фразы, которые реально встречаются в японских кофейнях: テイクアウト (to go), 店内 (for here), サイズアップ (upcharge за больший размер), おかわり (refill), ミルク少なめ / 多め (молока поменьше/побольше). С этими карточками заказывать кофе станет заметно проще.

Кофейные идиомы и сленг — что внутри
Приглашения: 「珈琲する？」 (пойдём покофейним?), 「コーヒーでもどう？」 (как насчёт кофе?), 「一杯やりませんか」 (не выпьем ли по чашке?).
Зависимость и любовь: 「コーヒー中毒」 (кофеман, досл. «кофейная зависимость»), 「コーヒーにハマってる」 (подсел на кофе), 「コーヒーなしではダメ」 (не могу без кофе), 「コーヒーは命」 (кофе — это жизнь).
Типично японское: 「モーニング」 (morning — комплексный завтрак с кофе, культура Нагои и не только), 「立ち飲みコーヒー」 (кофе стоя — отдельный жанр), 「サクッとコーヒー」 (быстренько кофе — сленг), 「自家焙煎」 (домашняя/своя обжарка — важнейший термин в Японии).
Ценитель: 「コーヒー通」 (кофейный сноб/знаток — не негативно, скорее уважительно), 「コーヒーに詳しいね」 (ты хорошо разбираешься в кофе — комплимент).
Каждая карточка имеет поле note с пояснением, когда и как это уместно сказать.
